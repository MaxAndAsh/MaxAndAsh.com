FREE PUBLISHING:
Upload these files to a public GitHub repository and enable GitHub Pages from Settings > Pages > Deploy from a branch > main > /(root).

The site is static, so it works in modern Chrome, Firefox, Edge, Safari and other standards-compliant browsers.
